Command Reference

Tailscale Funnel

Expose a local server to the public internet over HTTPS — no public IP, no port-forwarding, no firewall changes.

Prerequisites (one-time)

  • Tailscale installed on the device and logged into your tailnet (tailscale status shows it connected).
  • MagicDNS and HTTPS Certificates enabled — Admin console → DNS page.
  • Funnel enabled for your tailnet. The first funnel command prints a link to enable it; opening and approving that link is enough.

Expose a port

Serve a local server (here, port 8000) publicly. --bg runs it in the background and the config survives reboots.

sudo tailscale funnel --bg 8000

On the first run, it prints an enable link — open it and approve:

Funnel is not enabled on your tailnet. To enable, visit:
https://login.tailscale.com/f/funnel?node=...

Get your URL

tailscale funnel status

The public URL has the form https://<machine-name>.<tailnet-name>.ts.net/. The default public port is 443, so it has no port suffix.

This setup

Machine yash-ubuntu · tailnet tail3210fb.ts.net

Port 8000 → https://yash-ubuntu.tail3210fb.ts.net/

Add more apps — by port

Funnel allows only three public ports: 443844310000. Each app on a distinct port gets its own root URL. Max three apps this way.

sudo tailscale funnel --bg --https=8443 8080

Port 8080 → https://yash-ubuntu.tail3210fb.ts.net:8443/  (note the :8443 in the URL).

Add more apps — by path

Keep everything on 443 and split by URL path with --set-path. No three-app limit here — add as many as you want.

sudo tailscale funnel --bg --set-path=/app2 8080
sudo tailscale funnel --bg --set-path=/app3 9000
sudo tailscale funnel --bg --set-path=/app4 5000

/app2 → port 8080  ·  /app3 → port 9000  ·  /app4 → port 5000

Caveat: each app must work under its sub-path. Apps that load assets from absolute URLs (e.g. /static/main.js) render broken under /app3. Fix by setting the app's base-path / root-URL config, or put that app on a separate port instead.

Stop / disable

Turn off a specific funnel:

sudo tailscale funnel --https=443 off

Clear everything:

tailscale funnel reset

Notes & limits

  • Public ports: only 443, 8443, 10000. Three apps max by distinct port; unlimited by path on 443.
  • Adding more: no need to stop Funnel or re-visit the enable link — each command adds a mount alongside the others. Paths must be unique; / stays with the first app.
  • URL stability: the URL stays the same across reboots and reconnects. It changes only if you rename the machine, rename the tailnet, or delete and re-add the device (which can append -1).
  • Security: Funnel is fully public — Tailscale adds no auth. Your app's own login is the only thing protecting it, so keep that strong and rate-limited.
  • Verify anytime: tailscale funnel status lists every active mount and its URL.
