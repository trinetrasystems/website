YOLO26 on Jetson with DeepStream 7.1

End-to-end recipe to deploy YOLO26-S with TensorRT inference and RTSP streaming on a Jetson device. Commands and configs preserved exactly as tested locally.

JetPack 6.1
DeepStream 7.1
Installer SDK Manager
Storage SD card
01 /

Power Mode

Set the highest performance profile and lock clocks.

bash power-mode.sh 
sudo nvpmodel -p --verbose
sudo nvpmodel -m 2
sudo nvpmodel -q
sudo jetson_clocks
02 /

Ultralytics Setup

Clone Ultralytics and install with export extras.

bash setup-ultralytics.sh 
cd ~
pip install -U pip
git clone https://github.com/ultralytics/ultralytics
cd ultralytics
pip install -e ".[export]" onnxslim
03 /

DeepStream-Yolo Repo

Clone marcoslucianops' DeepStream-Yolo and copy the export script.

bash setup-deepstream-yolo.sh 
cd ~
git clone https://github.com/marcoslucianops/DeepStream-Yolo
cp ~/DeepStream-Yolo/utils/export_yolo26.py ~/ultralytics
04 /

Export YOLO26 Model

Download weights, install ONNX tooling, and export to ONNX.

bash export-yolo26.sh 
cd ultralytics
wget https://github.com/ultralytics/assets/releases/download/v8.4.0/yolo26s.pt

pip3 install --user onnxscript
pip3 install --user onnx onnxslim onnxscript

python3 export_yolo26.py -w yolo26s.pt --simplify --batch 1

cp yolo26s.onnx labels.txt ~/DeepStream-Yolo
05 /

Build Custom Inference Plugin

Set CUDA version and compile the YOLO custom parser.

bash build-plugin.sh 
cd ~/DeepStream-Yolo
export CUDA_VER=12.6
make -C nvdsinfer_custom_impl_Yolo clean && make -C nvdsinfer_custom_impl_Yolo
06 /

RTSP Server Dependencies

Install GStreamer RTSP server libraries for streaming output.

bash install-rtsp.sh 
sudo apt update
sudo apt install -y libgstrtspserver-1.0-0 libgstrtspserver-1.0-dev
07 /

Inference Config

Open the file and paste the contents below.

bash open-editor.sh 
nano config_infer_primary_yolo26.txt
config config_infer_primary_yolo26.txt 
[property]
# GPU device ID. On Jetson always 0 (single GPU)
gpu-id=0

# Pixel normalization: output_pixel = input_pixel * net-scale-factor
# 0.0039215697... = 1/255  → maps 0-255 to 0-1 (standard for YOLO)
# 1.0 = no normalization
net-scale-factor=0.0039215697906911373

# Input color format the model expects
# 0=RGB  1=BGR  2=GRAY  3=RGBA  4=BGRx
model-color-format=0

# Path to ONNX model (resolved relative to this config file)
onnx-file=yolo26s.onnx

# Path to TensorRT engine. Built from ONNX on first run if missing.
# Convention: model_b<batch>_gpu<id>_<precision>.engine
model-engine-file=model_b1_gpu0_fp16.engine

# INT8 calibration table - only used when network-mode=1 (INT8)
#int8-calib-file=calib.table

# Class labels file (one label per line, indexed 0..N-1)
labelfile-path=labels.txt

# Inference batch size. Must match engine file's batch dim
batch-size=1

# Inference precision
# 0=FP32  1=INT8  2=FP16  3=BEST (auto-select)
network-mode=2

# Number of detection classes the model outputs (COCO=80)
num-detected-classes=80

# Frame skipping
# 0=infer every frame  N=skip N frames between inferences (reuse last result)
interval=0

# Unique ID for this GIE - must match [primary-gie] gie-unique-id in app config
gie-unique-id=1

# Where this GIE runs in the pipeline
# 1=Primary (full frame)  2=Secondary (on detected objects from upstream GIE)
process-mode=1

# Network output type
# 0=Detector  1=Classifier  2=Segmentation  3=Instance-Seg  100=Other (custom)
network-type=0

# Bounding-box clustering applied to raw detections
# 0=GroupRectangles  1=DBSCAN  2=NMS  3=DBSCAN+NMS hybrid  4=None
cluster-mode=2

# Network input dimensions: channels;height;width (overrides ONNX dims)
infer-dims=3;640;640

# Letterbox resizing - preserve aspect ratio with padding
# 1=maintain aspect (pad)  0=stretch to fit
maintain-aspect-ratio=1

# Padding placement when maintain-aspect-ratio=1
# 1=symmetric (center)  0=asymmetric (right/bottom only)
symmetric-padding=1

# TensorRT workspace size (MB) - larger allows better kernel tactic selection
#workspace-size=2000

# Custom bbox parser symbol exported from custom-lib-path .so
parse-bbox-func-name=NvDsInferParseYoloCuda

# Compiled custom inference plugin (built in section 05)
custom-lib-path=nvdsinfer_custom_impl_Yolo/libnvdsinfer_custom_impl_Yolo.so

# Custom engine builder for ONNX models with non-standard ops
engine-create-func-name=NvDsInferYoloCudaEngineGet

[class-attrs-all]
# Confidence threshold - detections below this are dropped before clustering
# Range: 0.0 to 1.0  (lower=more detections, higher=stricter)
pre-cluster-threshold=0.25

# Max detections kept after NMS/clustering (per frame)
topk=300
08 /

DeepStream App Config

Pipeline definition: source, mux, GIE, OSD, RTSP sink.

bash open-editor.sh 
nano deepstream_app_config.txt
config deepstream_app_config.txt 
[application]
# Print FPS / latency stats to console
# 0=disabled  1=enabled
enable-perf-measurement=1

# How often (seconds) perf stats are reported
perf-measurement-interval-sec=5

[tiled-display]
# Composite multiple sources into a single tiled mosaic
# 0=disabled (single stream pass-through)  1=enabled (composite)  2=parallel demux
enable=1

# Tile grid layout (rows × columns must be ≥ number of sources)
rows=1
columns=1

# Output canvas dimensions
width=1920
height=1080

gpu-id=0

# NvBufSurface memory type
# 0=Default  1=CUDA Pinned  2=CUDA Device  3=CUDA Unified  4=Surface Array (Jetson)
nvbuf-memory-type=0

[source0]
enable=1

# Source type
# 1=Camera (V4L2)  2=URI  3=MultiURI  4=RTSP  5=Camera (CSI - Jetson only)
type=3

# Input URI - schemes: file://  rtsp://  http://
uri=file:///opt/nvidia/deepstream/deepstream/samples/streams/sample_1080p_h264.mp4

# Number of identical streams to spawn from this URI (good for stress testing)
num-sources=1

gpu-id=0

# Memory type for the hardware decoder output
# 0=Device  1=Pinned  2=Unified
cudadec-memtype=0

# Display sink DISABLED (needs X server, not available on headless)
[sink0]
enable=0

# Sink type
# 1=FakeSink  2=EglSink (display)  3=File  4=RTSPStreaming  5=Overlay (Jetson)  6=MsgConvBroker
type=2

# Sync output to pipeline clock
# 0=as-fast-as-possible (file/offline)  1=sync to wall-clock (live)
sync=0

gpu-id=0
nvbuf-memory-type=0

# RTSP streaming sink
[sink1]
enable=1
#Type - 1=FakeSink 2=EglSink 3=File 4=RTSPStreaming 5=Overlay
type=4
#1=h264 2=h265
codec=1
#1=CPU 0=GPU (Jetson uses hardware encoder via nvv4l2h264enc)
enc-type=0

# 0=async  1=sync to clock
sync=0

# Output bitrate in bits per second (4 Mbps here)
bitrate=4000000

#H264 Profile - 0=Baseline 2=Main 4=High
profile=0
# RTSP server settings

# RTSP listen port → stream URL: rtsp://<jetson-ip>:<rtsp-port>/ds-test
rtsp-port=8554

# Internal UDP port the encoder pushes RTP packets to
udp-port=5400

[osd]
# On-Screen Display: draws bboxes + labels on output frames
# 0=disabled  1=enabled
enable=1
gpu-id=0

# Bounding-box border thickness in pixels
border-width=5

# Label font size (points)
text-size=15

# Label text color: R;G;B;A  (each value 0.0–1.0)
text-color=1;1;1;1;

# Label background color: R;G;B;A
text-bg-color=0.3;0.3;0.3;1

# Font family - any system-installed font (Serif, Arial, Sans, DejaVu Sans, ...)
font=Serif

# Wall-clock overlay on output frames
# 0=hide  1=show
show-clock=0
clock-x-offset=800
clock-y-offset=820
clock-text-size=12
# Clock text color: R;G;B;A
clock-color=1;0;0;0

nvbuf-memory-type=0

[streammux]
# Stream multiplexer - batches multiple source frames into one inference batch
gpu-id=0

# Source mode
# 0=non-live (file - waits for all sources)  1=live (RTSP/camera - drops late frames)
live-source=0

# Frames per inference batch (should match GIE batch-size)
batch-size=1

# Microseconds to wait for a full batch before pushing partial (40000 = 40ms)
batched-push-timeout=40000

# Mux output frame dimensions (sources are scaled/composited to this)
width=1920
height=1080

# Pad to maintain aspect ratio when scaling sources to mux size
# 0=stretch  1=letterbox pad
enable-padding=0
nvbuf-memory-type=0

[primary-gie]
# Primary inference engine (first GIE in pipeline, runs on full frame)
# 0=disabled  1=enabled
enable=1
gpu-id=0

# Must match gie-unique-id inside the inference config file
gie-unique-id=1
nvbuf-memory-type=0

# Path to the inference config (the file from section 07)
config-file=config_infer_primary_yolo26.txt

[tests]
# Loop file source forever - useful for demos and continuous testing
# 0=stop at EOS  1=loop
file-loop=1
09 /

Run

Launch the DeepStream pipeline.

bash run.sh 
deepstream-app -c deepstream_app_config.txt
RTSP output — once running, the inferred stream is available at rtsp://<jetson-ip>:8554/ds-test
